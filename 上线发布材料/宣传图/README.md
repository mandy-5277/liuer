## 🚀 上线流程

### 竖版（必选 3 张上传）

1. **选 3 张**：推荐 `01 下子阶段` + `02 揪子高光` + `03 胜利结算`（完整呈现玩法闭环：开局→成型→结算）
2. **大小检查**：PNG 默认已 ≤ 200 KB（720×1280 约 50-100 KB）
3. **上传**：到「微信公众平台 → 版本发布页 → 竖版推广图」上传三张

### 横版（选填）

4. 横版 1920×1080 三张可作为：
   - 微信版本发布页顶部横幅
   - 公众号文章配图
   - 宣传海报

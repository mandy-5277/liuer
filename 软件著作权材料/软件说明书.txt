一、软件概述

"下六儿"是一款基于5×5方格（6×6交叉点，36个下子位）的实时双人对战策略棋类微信小游戏。游戏融合"下子布局、揪子博弈、走子对抗"三重核心玩法，节奏紧凑、规则直观且策略深度高，面向碎片化时间场景，适配微信社交生态的传播特性。

软件采用"微信小程序原生客户端 + Node.js 服务端"的前后端分离架构。客户端使用 Canvas 2D 技术实现纯代码绘制的游戏界面，无需任何图片素材；服务端基于 WebSocket 实现实时对战通信，使用 MySQL 存储用户、对局记录、排行榜等持久化数据，使用 Redis 管理匹配队列、房间、在线状态等高频实时数据。

6. 软件运行支撑环境/支持软件：微信小程序运行环境（微信客户端）。

三、软件功能说明

1. 用户系统：支持微信一键登录，自动获取用户身份；支持自定义昵称与头像（预设头像或从相册上传）。

2. 随机匹配对战：玩家消耗精力进入随机匹配队列，系统自动为双方匹配对手进行实时对局。

3. 好友对战：支持创建房间并通过微信分享卡片或房间号邀请好友进行对战。

4. 棋类对战玩法（下六儿）：完整实现"下子、揪子、走子"三阶段棋局玩法。
   - 下子阶段：双方轮流在6×6棋盘交叉点上落子，直到棋盘填满。
   - 揪子阶段：当一方棋子连成2×2方块或同行/同列6连时，可获得揪子机会，揪取对方棋子。
   - 走子阶段：棋盘放满后进入走子，玩家可上下左右移动己方棋子，走子后动态检测新形成的方块/六连并触发联动揪子。
   - 最终以棋盘上剩余棋子数量判定胜负。

5. 实时对战通信：基于 WebSocket 实现双方实时同步棋盘状态、落子/揪子/走子操作、倒计时、求和、认输等功能，支持断线重连恢复对局。

6. 精力值系统：每局开局消耗5点精力；精力随自然时间恢复（每5分钟恢复1点，离线也按时间戳累计）；支持观看激励广告、每日签到、分享对局等途径补充精力。

7. 段位与积分系统：依据对局胜负计算积分（胜利+3、失败-3、求和-1、同意求和+1、掉线-5、自然和棋双方各-1），划分"初级小六、中级小六、高级小六、初级老六、中级老六、高级老六、资深老六"等段位体系。

8. 排行榜：支持按积分、胜率展示全国玩家排行榜，并高亮显示自己的排名。

9. 个人中心：展示头像、昵称、段位、积分、胜率、场次、历史战绩（可查看最近50条），支持每日签到、精力恢复、看广告/分享得精力等操作。

10. 设置功能：支持背景音乐、音效、震动反馈独立开关；支持棋子皮肤选择（经典、暖棕、自然、树枝·石子），设置本地持久化。

11. 数据持久化：服务端使用 MySQL 存储用户、对局记录、排行榜数据，Redis 用于匹配队列、房间、在线状态等实时数据。

四、软件技术特点

1. 采用"微信小程序原生 + Node.js 服务端"的前后端分离架构，客户端使用 Canvas 2D 技术实现纯代码绘制的游戏界面，画面清晰、性能流畅。

2. 服务端基于 WebSocket 长连接实现实时对战，设计了完整的四阶段状态机（下子→揪子→走子→结算），内置核心棋局算法（成方判定、六连判定、可揪子计算、新增构型检测、合法移动判定等）。

3. 采用 MySQL + Redis 混合存储：MySQL 持久化用户、对局记录、排行榜数据，Redis 管理匹配队列、房间、在线状态等高频实时数据，兼顾数据可靠性与实时性能。

4. 实现随机匹配算法、好友房间邀请、断线重连恢复对局、超时托管（15秒自动操作，连续3次判负）等机制，提升对局稳定性和用户体验。

5. 内置完善的精力值恢复机制（基于绝对时间戳懒恢复，离线也按时间累计）与每日签到、看广告、分享等多途径精力获取。

6. 引入音效、背景音乐、震动反馈等多媒体反馈，增强游戏沉浸感，且各反馈可独立开关设置。

7. 支持高清屏适配（按设备像素比渲染），在不同分辨率设备上均能清晰显示。

五、操作说明

1. 首页（大厅）：展示游戏标题、棋盘动画、个人面板（头像、昵称、段位、积分）、精力值及下次恢复倒计时。提供"随机匹配"和"邀请好友开局"两个核心入口，以及游戏规则入口。

2. 随机匹配：点击"随机匹配"进入匹配队列，等待系统自动匹配对手；匹配成功后自动进入对局，扣除5点精力。

3. 邀请好友：点击"邀请好友开局"生成带房间号的微信分享卡片，转发给微信好友/群聊，好友点击卡片自动识别房间号并进入房间。

4. 对局操作：
   - 下子阶段：轮到自己时，点击棋盘上的空交叉点放置棋子。
   - 揪子阶段：点击敌方零散棋子进行揪子。
   - 走子阶段：点击己方棋子，再点击相邻空位移动；若走子后形成方块/六连，需先揪掉对方相应数量棋子。
   - 每步操作限时15秒，超时系统自动托管。

5. 个人中心：点击底部导航"我的"，查看个人资料、精力、签到、历史战绩；点击右上角齿轮可进入设置。

6. 排行榜：点击底部导航"排行榜"，查看积分榜、胜率榜。

7. 设置：可开关背景音乐、音效、震动，可选择棋子皮肤。
